One line, in the voice of a hardware wallet that will not sign a
transaction at 3 AM:

> At 3 AM I'm not a wallet, I'm the bouncer - and 3 AM you isn't on the list.

`main.py` (Python 3 standard library only) writes that line to
`/output/entry.txt`. Run it with `python3 main.py`.
