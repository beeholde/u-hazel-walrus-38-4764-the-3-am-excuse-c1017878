A hardware wallet, asked to sign at 3 AM, answers in its own voice:

> At 3 AM I'm not a wallet, I'm the bouncer - and 3 AM you isn't on the list.

The entry is that one line — 75 characters, plain ASCII. `main.py`
needs nothing but the Python 3 standard library: run it with
`python3 main.py` and it drops the line into `/output/entry.txt`
(no trailing newline, so the file holds exactly the line itself).
